# LLM-assisted interpretation (Section 2.9 of the manuscript)

This folder holds the materials of the auxiliary interpretation step: the code that called the OpenAI API, the prompts, the input files given to the model, and the raw outputs.

To be added by the authors after the run on the revised outputs (seven clusters):

- `code/` – the script(s) used to call the API
- `prompts/` – the prompt texts, exactly as sent
- `inputs/` – the files given to the model (the 120 terms with clusters, the network subgraphs, the characteristic terms of each period)
- `outputs/` – the raw model outputs, unedited
- `RUN.md` – model identifier, date of the run, number of runs (one), and parameters

The model output was used only as supplementary information; the interpretation reported in the manuscript was decided by the authors after cross-checking against the KH Coder outputs.
